# Habibi J1Gs for Windows

**[Download the latest version](https://github.com/Dhatab/habibi-j1gs-downloads/releases/latest)**

On the download page, open **Assets** and choose the file named
`Habibi-J1Gs-Setup-<version>.exe`.

## Install

1. Download the setup executable on a Windows 10 or Windows 11 PC (64-bit).
2. Close Habibi J1Gs if it is running, then run the installer.
3. Open Habibi J1Gs from the desktop or Start menu.

If you have an older copy, install this setup version once to enable online
updates. Your saved profiles and settings stay on your PC.

## Update

Click **Check for Updates** in the app's sidebar. When a newer version is
available, the app downloads it, verifies it, installs it, and restarts.

## Windows publisher notice

The initial installer is unsigned, so Windows may display an unknown-publisher
or SmartScreen notice. Download releases only from this repository.
